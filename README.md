# MB Design & Build

A modern architectural, interior design and construction website built with PHP, HTML, CSS and JavaScript. Designed to showcase projects, services, the firm's portfolio, galleries and company information through a clean and immersive web experience.

## Overview

**MB Design & Build** is a professional website for an architecture, interior design and construction firm. It showcases the firm's projects, design philosophy, services, gallery and company profile through a visually focused and responsive interface.

## Features

- **Modern Homepage** – Engaging hero section with video background.
- **About / Firm** – Company profile, design philosophy and firm information.
- **Projects Portfolio** – Dynamic project listing with categories and statuses.
- **Project Details** – Dedicated project pages with images and details.
- **Gallery** – Visual showcase of architecture and interior projects.
- **Gallery Viewer** – Dedicated gallery image viewing experience.
- **Services** – Overview of architecture, planning and interior design services.
- **Responsive Design** – Layout adapted for desktop, tablet and mobile.
- **Dynamic PHP Components** – Reusable header, footer and page components.
- **Terms & Information** – Structured terms and related content.

## Tech Stack

- **PHP** – Server-side development
- **HTML5** – Website structure
- **CSS3** – Styling, layouts and animations
- **JavaScript** – Interactive functionality
- **MySQL** – Database support where configured

## Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/Him895/mbdesign.git
```

### 2. Navigate to the project directory

```bash
cd mbdesign
```

### 3. Install local server

Install [XAMPP](https://www.apachefriends.org/) and start Apache (and MySQL if required).

### 4. Place the project

Place the project inside the XAMPP `htdocs` directory.

```text
C:\xampp\htdocs\mbdesign
```

### 5. Configure the project

Update the project configuration and database credentials in the relevant files under `includes/` if required.

### 6. Run the website

Open your browser and visit:

```text
http://localhost/mbdesign/
```
